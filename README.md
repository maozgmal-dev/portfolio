# Smart Opsh Phone
نظام إدارة صيانة ومبيعات ومخزون لمحل سمارت أوبشن هاتف.

## التشغيل
```bash
pip install -r requirements.txt
python app.py
```
ثم افتح `http://127.0.0.1:5000`

## النشر
